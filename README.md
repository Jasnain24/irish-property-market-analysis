Irish Property Market Analysis

An end-to-end data analysis project exploring 800,000+ property transactions across Ireland from 2010 to 2026 using Python, SQL, and data visualisation.

Data Source: Irish Property Price Register — propertypriceregister.ie

Key Findings

Average Irish property prices have grown significantly since 2012 post-crash recovery
Dublin consistently commands the highest average prices nationally
October and November see the highest sales volumes
New builds command a premium over second-hand properties

Tech Stack: Python | Pandas | SQLite | Matplotlib | Seaborn | Plotly

Analysis Notebooks

01_data_cleaning — raw data ingestion, encoding fix, cleaning 800k records
02_sql_analysis — 10 SQL queries answering real market questions
03_visualisations — 4 static charts and 1 interactive Plotly chart
